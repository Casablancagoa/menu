# Casablanca Goa

Restaurant menu — <https://goacasablanca.com/menu/>

- Food menu: `/menu/`, bar: `/menu/bar/`. Data comes from the published Google Sheet (URLs at the top of `menu.js`).
- Preview locally: `python3 -m http.server` → <http://localhost:8000/> (opening `index.html` as a file doesn't work).
- Test the CSV parser: `node test.mjs`
